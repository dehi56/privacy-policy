# 05. 投稿・運用

本リポジトリにはすでに **Threads自動投稿ツール**（`threads/`）と Pinterest 連携があります。
生成した動画の配信はこれと接続できます。

---

## 1. 出力フォーマット

| プラットフォーム | 比率 | 解像度 | 長さ | 備考 |
|---|---|---|---|---|
| Threads | 9:16 / 1:1 | 1080x1920 | 〜5分 | 本リポジトリで自動投稿可 |
| Instagram Reels | 9:16 | 1080x1920 | 〜90秒 | 冒頭1秒が勝負 |
| TikTok | 9:16 | 1080x1920 | 〜10分 | 音楽必須 |
| YouTube Shorts | 9:16 | 1080x1920 | 〜60秒 | |
| Pinterest | 9:16 / 2:3 | 1000x1500 | 〜15分 | 静止画も併用すると効く |

```bash
# 全プラットフォーム共通の縦型書き出し
ffmpeg -i input.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30" \
  -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k output.mp4
```

---

## 2. 本リポジトリのThreads自動投稿との連携

`threads/posts.json` に投稿内容を定義し、GitHub Actions（`.github/workflows/threads-post.yml`）が
スケジュール実行する構成になっています。セットアップ手順は `threads/SETUP.md` を参照してください。

動画を投稿する場合、メディアはURLで参照できる場所（S3 / R2 / GitHub Releases 等）に置く必要があります。
生成物そのものをこのリポジトリにコミットしないでください（`assets/` はgitignore済み）。

---

## 3. 運用のリズム

| 頻度 | 作業 |
|---|---|
| 毎日 | 投稿1〜2本、コメント返信 |
| 週1 | 生成バッチ（5〜10本まとめて作る） |
| 月1 | 数字を見て方向修正、LoRAの再学習検討 |

生成は「毎日ちょっとずつ」より**週1でまとめて回す**方が効率的です。
GPUを長時間占有するので、寝ている間にバッチを流すのが基本になります。

---

## 4. AI生成であることの明示

**必ず明示してください。** 現在、主要プラットフォームはAI生成コンテンツのラベリングを義務化する方向です。

- プロフィールに「AI generated / AIによる架空の人物です」と明記
- 投稿にハッシュタグ（#AIart #AIgenerated #AI生成）を付ける
- 各プラットフォームのAIコンテンツ表示設定をONにする

隠すメリットはありません。むしろ「AIでここまで作れる」というのが訴求点になります。
バレてから釈明するのが最悪のパターンです。

---

## 5. 数字の見方

追うべき指標は視聴維持率（特に最初の3秒）です。フォロワー数は後からついてきます。

- 冒頭1秒に「顔のアップ」か「動きの変化」を置く
- 5秒クリップを2〜3本繋いで10〜15秒にする方が維持率は上がりやすい
- 同じキャラで統一する（毎回顔が違うと記憶に残らない）
